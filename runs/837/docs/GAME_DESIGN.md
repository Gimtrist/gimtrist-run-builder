# 《桃李研究室》V2 设计说明

## 体验定位

一款单机、回合制、像素实验室外观的高校导师模拟网页游戏。

V2 的视觉目标是从文字卡片转向“可爱的像素研究室”：学生坐在工位上，白板显示论文/项目/职称进度，门口代表招生，会议桌代表组会。行动入口直接融入实验室物件，玩家第一屏就能点门招生、点白板推进课题/论文、点工位指导或抽查学生。玩法内核仍然是随机事件、多结局和选择后果，不做小窗口挂机，也不做实时放置。

## 玩家循环

1. 每个学期拥有 4 次行动机会。
2. 在实验室行动台中选择招生面试、单独指导、开组会、组内协作、抽查状态、立项课题、推进论文、论文投稿、申请项目、冲职称、添置设备、制定规则、署名安排、校友联络、全组休息等操作。
3. 行动会改变全局资源和学生个体状态，并可能触发随机事件。
4. 学院任务给出 3 个一局内目标，完成后获得奖励并刷新新目标。
5. 学生会通过面试进入课题组，隐藏特质会在组会、抽查、署名或压力事件中暴露。
6. 论文进度满格会形成可投稿稿件；投稿后可能录用、返修或拒稿。
7. 项目、职称进度满格会转换为长期成果，并提升课题组等级和招生上限。
8. 每学期结束时，学生毕业进度、压力、信任和状态结算；学生可能毕业，也可能走向崩溃、摸鱼或离开。
9. 每年末触发年度考核，根据产出、培养、信任、风险和行政压力给出评价，并转化为下一年的资源、压力或 KPI 路线。
10. 八年生涯结束时，根据论文、项目、毕业学生、学生信任、行政压力、年度考核与伦理风险结算多结局。

## 学生系统

每名学生拥有：

- 基础信息：姓名、硕士/博士、培养阶段、像素头像颜色。
- 可成长维度：研究力、写作、主动性、抗压。
- 关系与状态：信任、压力、摸鱼倾向、当前状态。
- 产出维度：毕业进度、论文贡献。
- 隐藏特质：例如摸鱼雷达、ddl 爆发型、玻璃心天才、社交悍匪、复现洁癖、论文缝合怪、正义雷达、夜行动物。

学生不是自动挂机资源点。学生的变化主要来自玩家行动、学期结算和随机事件。

## 招生系统

- 初始课题组只能容纳 2 名学生。
- 论文、项目、职称和声望提升后，课题组等级提高，并逐步扩大招生上限。
- 面试只显示部分维度和标签，不显示隐藏特质。
- 候选人的隐藏特质会在后续事件中改变培养路线。
- 高等级会解锁更复杂候选人：设备玄学研究员、跨校交换生、AI 工具狂热者、反内卷观察员、未来 PI 苗子。

## 学院任务

- 每局同时显示 3 个目标，例如招生、开组会、抽查、添置设备、改规则、揭示隐藏特质、发表论文、学生毕业。
- 目标完成后立刻奖励经费、声望、信任、行政缓解或论文进度。
- 已完成目标不会重复出现，目标池会根据当前状态补新目标。
- 目标不是强制主线，玩家仍可走坏导师路线或自由探索。

## 年度考核

- 年度考核在每次进入新年份时触发，不占用普通行动次数。
- 评分综合论文、稿件、项目、职称、课题完成、毕业学生、学生信任、校友联络、同门协作、行政压力、伦理风险和最高学生压力。
- 结果分为优秀、合格、预警、危机；评价会写入本局考核档案。
- 玩家可选择申请学院资源、给学生补偿减压，或硬冲下一年度 KPI。
- 低分考核会解锁学院督导旁听类随机事件，高分考核会解锁优秀经验分享类随机事件。
- 连续优秀会解锁“年度优秀标本”结局方向，但高风险、高行政压力会破坏这条路线。

## 课题线系统

课题线把“论文进度”拆成具体研究方向：

- 玩家通过“立项课题”选择一个模板，并分配学生负责人。
- 论文、项目和组会行动会推进所有 active 课题线。
- 课题完成后转化为论文进度、声望、经费或伦理风险变化。
- 部分课题会降低风险，例如数据追踪和署名透明化；部分课题来钱快但风险高，例如横向项目复用。
- 课题线会触发专属事件：核心假设卡住、旧数据挖出突破等。

## 同门协作

- 玩家可以选择两名学生和一条课题线进行协作。
- 协作成功会推进课题线，并提升两名学生的研究/写作能力与信任。
- 协作失败仍会推进少量进度，但会提高压力、降低信任，并记录协作冲突。
- 主动性、抗压、压力、隐藏特质和实验室规则会影响协作成败。
- 协作会触发专属事件：同门互相讲懂问题、争论谁在拖后腿等。

## 校友系统

- 学生毕业后会进入校友档案，而不是只增加毕业数量。
- 校友保留姓名、项目、隐藏特质、毕业时信任、毕业去向和可提供的回响。
- 玩家可以通过“校友联络”消耗行动联系毕业生。
- 校友可能带来横向合作、学术合作、推荐学生、设备赞助或真诚反馈。
- 校友也会触发随机事件，例如推荐新学生、毕业后真心邮件。

## 投稿系统

- 论文进度达到 100 后不再直接发表，而是形成一份可投稿稿件。
- 玩家通过“论文投稿”选择投稿档位：友好型工作坊、稳妥核心期刊、顶刊冲刺、神秘快速通道。
- 投稿结果包括录用、返修和拒稿。
- 录用增加论文数、声望和经费；返修保留稿件并回流论文进度；拒稿会回流部分进度但打击信任。
- 危险快速通道录用率高但伦理风险显著上升，并可能触发后续事件。

## 组会与抽查

- 开组会：推进论文，提升部分能力，但也会增加压力；可能暴露 ddl 爆发型、压力过载等事件。
- 抽查状态：可能抓到摸鱼，也可能发现学生真的被实验、代码或审稿卡住。
- 单独指导：提高学生能力与信任，降低压力，适合修复关系。

## 设备与实验室规则

设备是长期经营层，不是装饰：

- 会发光的大白板：提高组会收益，降低组会压力。
- 咖啡角与零食箱：提高休息收益，缓和学期末压力。
- 像样的学生工位：提高论文行动收益，扩大学生上限，降低摸鱼倾向。
- 数据服务器：降低伦理风险，并触发数据恢复类事件。
- 午睡沙发：帮助高压学生在学期末不至于崩溃。
- 会议摄像头：提高项目/会议收益，但行政压力略高。

实验室规则持续影响长期路线：

- 补助制度：丰厚补助消耗经费但稳定信任；低补助增加经费但提高压力与摸鱼。
- 署名规则：贡献透明降低风险；导师优先提高短期收益和长期反噬。
- 毕业要求：宽松毕业更容易送走学生；严格毕业提高论文收益但增加压力。

## 地狱梗路线

“强行安排一作”“抢一作”“公开点名摸鱼”“这很简单你们自己改改”等选项允许存在，但不能成为无代价最优解。

系统规则：

- 短期可以提高论文、项目或声望。
- 必须提高伦理风险、降低学生信任或增加学生压力。
- 风险累计后触发匿名墙、署名风波、联名邮件、离组、举报等反噬。
- 结局会区分“高产但压榨”与“成果和关系兼顾”。

## V2 成功标准

- 无网络请求也可完整开局、招生、培养学生、触发事件、达成结局。
- 刷新页面可恢复未结束进度；可导入/导出 JSON 存档。
- V1 存档可迁移为 V2 学生名单。
- 学生系统必须影响事件和结局，而不是只作为展示。
- 行动入口必须嵌入像素实验室首屏，不能依赖玩家滚动到页面下方寻找操作框。
- 学院任务必须显示在 UI 中，并能提供实际奖励。
- 年度考核必须在换年时触发，并影响资源、学生压力、风险、任务或结局。
- 课题线必须显示负责人、进度和完成奖励，并能通过行动推进。
- 投稿系统必须让稿件经历录用、返修或拒稿，而不是论文进度满格自动发表。
- 同门协作必须能推进课题线，并可能产生正向互助或负向冲突。
- 校友系统必须保留毕业生档案，并在后续行动或事件中产生反馈。
- 设备和实验室规则必须影响数值、事件或结局，而不是只作为菜单。
- 画面从文字面板升级为像素实验室 UI，且在桌面与手机上不重叠。
