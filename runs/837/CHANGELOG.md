# Changelog

## V2 正式版 - 2026-07-16

- 将主界面改造为像素实验室：白板、招生门、会议桌、工位、学生像素小人和状态气泡。
- 将行动入口融入实验室画面：招生门、白板、工位、组会桌、设备区和咖啡角直接作为可点击操作点。
- 将学生像素小人改为 sprite sheet 渲染，并扩大状态气泡，完整显示隐藏特质名称。
- 新增学生个体系统：能力、压力、信任、摸鱼倾向、论文贡献、毕业进度与隐藏特质。
- 新增招生面试：候选人展示可见维度，隐藏特质入组后通过事件暴露。
- 新增组会、抽查、单独指导、署名安排与全组休息等行动。
- 新增学生相关随机事件：隐藏爆发、署名风波、匿名墙、会议名额、设备报错、审稿大修。
- 新增实验室设备系统：白板、咖啡角、学生工位、数据服务器、午睡沙发、会议摄像头会影响效率、压力、风险和学生上限。
- 新增实验室规则系统：补助、署名、毕业要求会持续影响学期结算、署名后果和毕业阈值。
- 新增学院任务系统：每局显示 3 个短期目标，完成后奖励经费、声望、信任、论文进度或行政缓解。
- 新增年度考核系统：每年末根据产出、培养、信任、风险和行政压力评分，并触发资源申请、学生减压或硬冲 KPI 的选择。
- 新增年度考核后续事件：低分可能触发学院督导旁听，高分可能触发优秀经验分享。
- 新增课题线系统：玩家可以立项具体研究方向，分配学生负责，并通过论文、项目、组会行动推进。
- 新增课题线事件：核心假设卡住、旧数据里挖出突破。
- 新增投稿系统：论文进度满格先形成稿件，玩家选择投稿档位后可能录用、返修或拒稿。
- 新增投稿事件：返修风暴、快速拒稿、灰色快速通道。
- 新增同门协作系统：两名学生可结对子推进课题线，成功会互相成长，失败会产生冲突。
- 新增同门协作事件：协作火花、同门冲突。
- 新增校友系统：毕业生进入校友档案，可通过校友联络带来合作、推荐学生、经费或真诚反馈。
- 新增校友事件：校友推荐新学生、毕业后的真心邮件。
- 新增年度考核结局方向：连续优秀且风险可控时可进入“年度优秀标本”路线。
- 扩展高级候选人：设备玄学研究员、跨校交换生、AI 工具狂热者、反内卷观察员、未来 PI 苗子。
- 新增设备/规则相关事件：数据恢复、补助讨论、毕业线争议。
- 新增学生专属事件：摸鱼雷达反转、玻璃心天才崩溃、社交悍匪合作、论文缝合怪图表、夜行动物透支。
- 新增荒诞地狱梗路线：公开点名、强行安排一作、抢一作等选择会带来短期收益和长期反噬。
- 扩展结局：桃李满门、现代化桃李工坊、制度怪物、学术包工头等学生系统相关结局。
- 增加 V1 存档到 V2 学生名单结构的迁移逻辑。
- 更新 README、设计文档、内容边界与静态校验脚本。
