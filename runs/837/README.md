# 桃李研究室

> 一款像素实验室外观、随机事件多结局内核的单机高校导师模拟网页游戏。

**桃李研究室**让你从一间刚挂牌的课题组办公室出发，在八年学术生涯里招生、带学生、开组会、抽查状态、推进论文、申请项目、处理署名风波，并在随机事件里承受每一次选择留下的回声。

本作不做小窗口挂机，也不做实时放置。它走的是原有的回合制路线：每学期有限行动，行动后可能触发事件，长期数值和学生关系共同导向不同结局。

- 已升级为 V2 像素实验室 UI：中央研究室场景、学生像素小人、实验室物件行动入口、学生名单和事件日志。

- 已加入学生个体系统：每名学生都有能力、信任、压力、摸鱼倾向、毕业进度、论文贡献和隐藏特质。
- 已加入招生面试：候选人展示部分维度，隐藏特质入组后通过事件暴露。
- 已加入组会、抽查、单独指导、署名安排、坏导师地狱梗路线。
- 已加入设备与实验室规则：设备长期改变效率，补助、署名、毕业要求会持续影响学生状态。
- 已加入学院任务系统：本局目标会引导玩家体验招生、组会、抽查、设备、规则、论文和毕业，并提供奖励。
- 已加入年度考核系统：每年末根据论文、项目、毕业、信任、风险和行政压力给出学院评价，并触发资源、减压或硬冲 KPI 的选择。

- 已加入课题线系统：玩家可以立项具体研究方向，分配学生负责，研究/组会/项目会推进课题。
- 已加入投稿系统：论文进度满格会形成稿件，投稿后可能录用、返修或拒稿。

- 已加入校友系统：毕业生会进入校友档案，后续可联络并带来合作、推荐学生或真诚反馈。
- 已扩展高级候选人和学生专属事件，让隐藏特质更频繁地改变剧情走向。
- 已保留随机事件与多结局内核，并新增学生相关结局方向。
- 仍保持纯静态网页，无依赖、无后端、无联网请求。

## 你会经历什么

- 自定义教师称呼、所在学校与课题组名称。
- 初始只能招 1-2 名学生，课题组等级提升后扩大招生上限。
- 随等级解锁更复杂的候选人，例如设备玄学研究员、跨校交换生、AI 工具狂热者和未来 PI 苗子。
- 面试学生时只能看到研究力、写作、主动性、抗压和若干标签；隐藏特质需要在后续事件中发现。
- 完成本局学院任务，获得经费、声望、信任、论文进度等奖励。
- 每年末面对年度考核，选择争取资源、给学生减压，或继续硬冲 KPI；连续优秀会影响长期结局。
- 立项 AI 审稿、匿名墙反馈、署名透明化工具、毕业预警等课题线，并把它们推进成论文成果。
- 把完成的稿件投向工作坊、核心期刊、顶刊或危险快速通道，面对录用、返修和拒稿。
- 安排同门协作，让学生互相带飞，或处理协作失败后的关系裂缝。
- 联系毕业校友，获得合作机会、推荐生源、经费支持或对培养方式的反馈。
- 每学期直接在实验室行动台里安排招生面试、单独指导、开组会、抽查状态、推进论文、论文投稿、署名安排或全组休息等操作。
- 添置白板、咖啡角、学生工位、数据服务器等设备，改变论文效率、压力、风险和招生上限。
- 制定补助、署名、毕业要求等实验室规则，让制度持续改变事件走向。
- 抽查可能抓到摸鱼，也可能发现学生真的卡在实验、代码、审稿或压力里。
- 可以走公平培养路线，也可以选择“强行安排一作”“抢一作”等荒诞地狱梗；坏操作会带来短期收益和长期反噬。
- 八年后根据论文、项目、毕业学生、学生信任、伦理风险、行政压力等进入不同结局。

## 核心特色

| 像素实验室 | 学生以像素小人在实验室里活动，招生门、白板、工位和组会桌直接承担行动入口。 |
| --- | --- |
| 学生养成 | 学生不是一个数字，而是有能力、压力、信任、毕业进度和隐藏特质的个体。 |
| 经营层 | 设备和实验室规则会长期影响效率、压力、风险、摸鱼和毕业。 |
| 学院任务 | 一局内会给出短期目标，引导玩家尝试系统并获得奖励。 |
| 年度考核 | 每年末按产出、培养、信任、风险和行政压力评分，并把奖励或惩罚变成下一年的路线选择。 |
| 课题线 | 具体研究方向会被学生负责并推进，完成后转化为论文、声望、经费或风险变化。 |
| 投稿系统 | 稿件需要选择投稿档位，可能录用、返修或拒稿，不再自动发表。 |
| 同门协作 | 学生之间会互相学习、推进课题，也可能因为制度和分工产生冲突。 |
| 校友回声 | 毕业生不会只变成数字，会进入档案并在后续事件里继续影响研究室。 |
| 随机事件 | 组会、审稿、匿名墙、设备报错、会议名额、署名风波等事件会改变长期路线。 |
| 选择有代价 | 地狱梗选项有短期收益，但会提高伦理风险、压低信任并触发反噬。 |
| 完全单机 | 无登录、无联网社交、无数据上传。打开网页就能玩。 |
| 浏览器存档 | 自动存档、JSON 导入导出，以及独立保留的校史档案。 |

## 结局方向

- **桃李满门**：学生顺利毕业，关系和成果都留下回声。
- **现代化桃李工坊**：设备、制度和学生培养都没有失控。
- **同门互助网络**：学生学会互相解释、互相补台，而不是所有问题都压向导师。
- **校友会还亮着**：毕业后仍有人回来合作、推荐新人或说一句真心话。
- **年度优秀标本**：连续几年考核优秀，同时没有把学生和风险推到失控。
- **制度怪物**：规则越来越厚，学生的声音越来越薄。
- **学术包工头**：论文很多，但学生毕业后很少再提那间办公室。
- **一路卷到院士候选**：高声望、高产出与更厚的会议材料并存。
- **学生口中的好导师**：头衔未必最耀眼，但有人多年后仍会发来消息。
- **从实验室走向会议室**：资源协调与行政路线的另一种成功。
- **学术档案室的长夜**：风险最终变成需要逐页解释的材料。
- **课题组的灯一盏盏熄了**：当信任被透支，学生会用离开回应。

## 本地运行

不需要安装依赖，也不需要后端服务。

```powershell
# 进入项目目录后
node scripts/verify-static.mjs
```

随后用浏览器打开 `index.html` 即可开始游戏。

## 技术说明

- 原生 HTML、CSS、JavaScript
- 浏览器 `localStorage` 存档与校史档案
- V1 存档会尝试迁移到 V2 学生名单结构
- 无 API、无数据库、无追踪脚本
- GitHub Actions 校验与 GitHub Pages 静态部署

## 内容说明

本作以虚构、荒诞的方式调侃科研生态中的压力、沟通困境与网络共鸣。涉及数据造假、滥用学生劳动、署名压榨或压制反馈的选择，都有明确的系统性代价与反噬；不影射真实学校、个人或具体事件。

详细的内容写作规则见 [docs/CONTENT_BIBLE.md](docs/CONTENT_BIBLE.md)。

## 项目结构

```text
├── index.html                         # 游戏页面与 V2 像素实验室结构
├── styles.css                         # 像素风 UI、学生小人与响应式布局
├── game.js                            # 回合、学生、招生、事件、结局、成就与存档
├── docs/
│   ├── GAME_DESIGN.md                 # 玩法与系统设计
│   └── CONTENT_BIBLE.md               # 语境梗库与写作边界
├── scripts/verify-static.mjs          # 发布前静态校验
└── .github/workflows/deploy-pages.yml # 校验并部署 GitHub Pages
```

## 部署

推送到 `main` 后，GitHub Actions 会自动运行静态校验，并通过 GitHub Pages 发布。
