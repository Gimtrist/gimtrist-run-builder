# Security Policy

## Supported versions

KhelZon is a static client-side web app. Only the latest version on the `main` branch is actively maintained.

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

If you discover a security issue, report it privately:

1. Open a [GitHub Security Advisory](https://github.com/pradipNP/khelzon/security/advisories/new) on the repository, **or**
2. Contact the maintainer through their GitHub profile

Include:

- Description of the issue
- Steps to reproduce
- Impact assessment (if known)
- Suggested fix (optional)

We will acknowledge your report as soon as possible and work on a fix. We appreciate responsible disclosure.

## Scope notes

KhelZon runs entirely in the browser with local storage. There is no backend server. Reports about third-party dependencies (browser extensions, CDN fonts) are generally out of scope unless they affect KhelZon directly when served from this repository.
